# Proyecto Machine Learning - Bank Marketing

## Descripción

Este proyecto utiliza el dataset **Bank Marketing** para predecir si un cliente aceptará un depósito a término. Se entrenaron y evaluaron distintos modelos de clasificación supervisada para identificar los factores más relevantes en la decisión del cliente.

## Entorno de ejecución

El proyecto se ejecutó utilizando **Python 3.13.5**.

## Instalación de librerías

Todas las librerías necesarias se encuentran listadas en el archivo `requirements.txt`. Para instalarlas localmente, se recomienda crear un entorno virtual e instalar con el siguiente comando:

```bash
pip install -r requirements.txt
```
